# TEDxTUWien Speaker Timer

Full-screen countdown timer for speakers at TEDxTUWien. Pick a time, press Start, it counts down to zero and then counts the overtime.

- Colour: white, yellow in the last 60 s, orange in the last 30 s, red from 0 and while in overtime (shown as +MM:SS).
- Keys: Enter start, Space pause/resume, R new time, F full screen.
- Deep links: ?m=12 (minutes) or ?t=90 (seconds) preselect the time.

Static page, no build step, no third-party requests. Served by GitHub Pages at https://timer.tedxtuwien.at/
